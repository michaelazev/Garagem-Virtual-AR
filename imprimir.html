Garagem Virtual AR

1) escaneie o QR para abrir o site  ·  2) aponte a câmera para o marcador

ABRIR O SITE
Gere com npm run qr (ou npm run qr -- URL_DO_DEPLOY).
MARCADOR AR
Aponte a câmera aqui — a concessionária 3D aparece em cima.
  1. No PC: npm start e abra http://localhost:8080/ (a câmera funciona em localhost).
  2. No celular: um link HTTPS — npm run tunnel (Cloudflare) ou publique no GitHub Pages / Netlify. Depois npm run qr -- SUA_URL gera o QR de cima.
  3. Abra o link, dê permissão de câmera e aponte para o marcador. Botão "Sem câmera" mostra o 3D inteiro.
Dicas: imprima o marcador (~8–10 cm) — apontar para a tela do notebook falha muito (brilho/reflexo). Mantenha o marcador inteiro no quadro, de frente, boa luz, ~15–40 cm.
